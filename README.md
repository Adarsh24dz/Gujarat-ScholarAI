# Gujarat ScholarAI

A multilingual AI-powered scholarship and education benefits assistant.

## Objective
Help students discover relevant Gujarat government scholarships, understand eligibility criteria, required documents, and application procedures using official government sources.

## Technology Stack
- Python
- LangChain
- ChromaDB
- FastAPI
- Streamlit
- Docker

## Project Status
Currently under development.

## Key Features
- Document-based question answering
- Multilingual support
- Source citations
- Scholarship eligibility information
- RAG-based retrieval system
